# SkillPilote Day 13

## Project Description
This practical demonstrates how to create a README file,
use Git for version control, and push the commit to AWS CodeCommit.

## Objectives
- Create a README.md file.
- Stage and commit the file locally.
- Push the commit to AWS CodeCommit.
- Verify the file in the AWS Management Console.

## Technologies Used
- Git
- AWS CodeCommit
- Windows PowerShell

## Result
The README file is created and prepared for committing
and pushing to the AWS CodeCommit repository.
